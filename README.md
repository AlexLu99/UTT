# Universal Textual Teaching for LLMs

Project website for Universal Textual Teaching (UTT).

**Zhanyi Lu and Huan Wang — Westlake University**

Website: https://alexlu99.github.io/UTT-Webpage/

This repository contains the static project website, paper figures,
and full text Primer examples, including MathVerse multimodal results. The research code repository and arXiv link
will be added when available.

Edit `index.html`, `styles.css`, and `app.js` to update the page.
All fonts and formula assets are included locally; no build step is needed.
GitHub Pages publishes the `main` branch from its root directory.

The page follows the academic layout of [OBS-Diff](https://alrightlone.github.io/OBS-Diff-Webpage/).
Third-party font and KaTeX licenses are included with their assets.
